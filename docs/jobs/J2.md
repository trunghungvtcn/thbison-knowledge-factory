## Minimal patch (J2 allowlist only)

1. `scripts/jobs/j2_source_only_pytest.py` — collect the suite, **deselect** (not skip/xfail) the six nodeids when the required asset is absent, run the rest, write JUnit + sidecar JSON (`NOT_RUN`).
2. `.github/workflows/verify.yml` — call that runner; always upload `j2-junit.xml` / `j2-summary.json` as `junit-${HEAD_SHA}`.
3. `docs/jobs/J2.md` — this note.

Out of scope: `tests/*.py`, algorithm code, contractor repo `pipeline-lab-contractor-m1-m5@afac091e60bb6c8a0f0630964e43f5e80951267c`, putting corpus/zip on GitHub.

If a required asset **is** present locally, the corresponding tests **run**. GitHub checkout will not have them.

The inventory is closed against run 34429494332. A newly added asset-bound test that is not listed will fail CI rather than be silently dropped.

## Reproduction

From a clean clone of this branch (Python 3.12, matching `.python-version` and CI `setup-python: "3.12"`):

```bash
python -m pip install -r requirements-dev.txt
python -m pip check
python -m compileall -q src scripts
python scripts/verify_migration_payload.py
python scripts/jobs/j2_source_only_pytest.py \
  --junitxml=j2-junit.xml \
  --summary-json=j2-summary.json
echo "exit:$?"
python -c "import json; print(json.load(open('j2-summary.json')))"
```

Expected on a source-only tree (assets absent):

- `exit:0`
- `passed=413`, `failed=0`, `skipped=0`, `not_run_count=6`
- JUnit contains the 413 executed tests only (the six do **not** appear as skipped/xfailed)
- sidecar lists the six nodeids with `"status": "NOT_RUN"`

Reproduce the **baseline failure** at `3f1f125` (full suite, no runner):

```bash
git checkout 3f1f125f3ccb6b5fbf173c2aa0e10b5d3b30584b
PYTHONPATH=src python -m pytest -q
echo "exit:$?"
```

Expected: `6 failed, 413 passed`, `exit:1`.

## What this runner does not do

- No `pytest.skip`, `pytest.xfail`, `pytest.mark.skip`, or `addopts` skip.
- No edits under `tests/`.
- No credentials, private corpus, or real snapshots committed.
- No reuse of the Actions log as a substitute for a fresh JUnit.
